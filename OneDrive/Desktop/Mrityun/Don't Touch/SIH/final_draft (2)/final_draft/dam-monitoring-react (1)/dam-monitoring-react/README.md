# DamSentinel AI — React Frontend

Frontend-only React/Vite demo for an intelligent dam, hydropower, overflow and flood-risk monitoring concept.

## Included
- React + Vite frontend only
- 8 uploaded videos in order: V1 → V8
- Video scenario player with previous/next controls and search
- Dam/reservoir hero section
- End-to-end risk workflow
- Smart monitoring dashboard mockup
- GIS incident visualization
- Overflow early-warning section
- Related project visual library

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

The project intentionally contains no backend, database, API, authentication or server code.
